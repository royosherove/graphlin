No rule for every library.
Jev interprets the supplied code, including wrapper implementations. Local helpers capture context and exact references. Missing context keeps a relationship tentative or triggers bounded enrichment.

        
Privacy starts before the first call.
Local rules remove prohibited content before Jev A sees it. Jev adds contextual redaction over permitted content. If either pass is unavailable, safe activity stays visible and the agent continues.
